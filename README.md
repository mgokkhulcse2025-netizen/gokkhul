# ✨ Chat with Your PDF using Google Gemini (RAG)

A Retrieval-Augmented Generation (RAG) web application built with **Streamlit**, **LangChain**, **FAISS**, and **Google Gemini** that lets you upload any PDF and ask context-grounded questions.
